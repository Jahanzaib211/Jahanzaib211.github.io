# Contributing

1. Branch from `main`.
2. Change `content`, `src` or `scripts`. Do not edit generated HTML by hand.
3. Keep the four languages in step. `npm test` compares them.
4. Run `npm run build` and `npm test`.
5. Open a pull request. Do not merge while a check is failing.

Read [AGENTS.md](AGENTS.md) for the wording and company rules.
