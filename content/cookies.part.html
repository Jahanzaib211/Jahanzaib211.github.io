Cookies

This website does not set cookies, so there is no consent banner.

What is stored in your browser

The site keeps a short note of which help messages you have already seen, using session storage. It contains nothing about you and disappears when you close the tab. What you type in the discovery form stays in the open page until you send or leave.

Services that deliver the site

Our hosting and network providers process technical data such as IP addresses to deliver pages and protect them. If you follow a link to another site, such as WhatsApp, GitHub or LinkedIn, that site applies its own cookie rules.

If this changes

If we ever add something that needs consent, we will ask first and update this page. Questions are welcome at Jahanzaib@alilabsx.com. See also our privacy policy.
