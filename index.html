FLAGSHIP · 01 / 04

Nova Botsa self-hosted AI bot team

Problem

Most AI assistants are one chat window that forgets everything. A real team needs bots with clear roles that keep working over time and can hand work to each other.

Approach

Nova Bots runs a team of long-lived bots, each with its own role, instructions, model and chat history. Bots message each other and share group chats, and a Main Bot manages the rest. It runs as a desktop app, in the browser or in a container, and a multi-tenant sign-in portal puts each team on its own isolated host.

NovaThe Agent's Computer

Problem

Most AI coding agents are a black-box chat window: you can't see what they're doing, or trust the result, until it's already done.

Approach

Nova gives the agent an actual computer: a live, streaming six-facet view (Files, Terminal, Editor, Browser, Activity, Review) so you watch it work in real time, with sub-agents, memory and per-thread sandboxes handling execution.

03 / 04

Locoa local inference lab

Problem

Running models on your own GPU usually means a pile of separate servers, silent model swaps when memory runs out, and assistants that write to long-term memory without asking.

Approach

Loco puts local models behind one OpenAI-compatible endpoint with deterministic routing. It only loads a model when it fits in VRAM, and memory is proposed for your approval, never written on its own. A zero-dependency local UI shows the pipeline live, and /metrics exposes Prometheus counters.
